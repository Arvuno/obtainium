# Contributing to Obtainium

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Obtainium.git`
3. Open the project in Android Studio
4. Build and run on a device or emulator

## Making Changes

* Follow the existing code style and Kotlin conventions
* Write clear, descriptive commit messages
* Add tests if applicable
* Ensure the app builds successfully before submitting

## Pull Request Process

1. Create a feature branch from `main`
2. Make your changes and commit them
3. Push to your fork and open a pull request
4. Respond to any review feedback

## Code of Conduct

Please be respectful and constructive in all interactions.
